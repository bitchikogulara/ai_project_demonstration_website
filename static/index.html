Introduction & Multi-Agent Search

Prepared by: Bitchiko Gularashvili  |  Université d’Évry Paris-Saclay  |  Academic Year: 2025–2026

The objective of this project is to study search algorithms for the simultaneous control of $n$ Pac-Men moving inside a connected 2D grid labyrinth. The target is to locate a sequence of simultaneous spatial movements that gathers all Pac-Men onto the same cell in the absolute minimum number of time units.

Key System Rules:

  • Simultaneity: At each time unit, every Pac-Man can make a move simultaneously.
  • Movement Slack: A Pac-Man is allowed to "stay still" during a tick, or move exactly 1 cell in any of the cardinal directions (Up, Down, Left, Right). No diagonal transitions are allowed.
  • Sharing Cells: Multiple Pac-Men are legally allowed to share the same cell at any given point in time (there is no collision/blocking between agents).
  • Connectivity: The grid layout is connected, ensuring there exists at least one legal pathway between any two empty cells.

Multi-agent pathfinding and convergence problems belong to the family of **combinatorial state space searches**. As the number of agents $n$ scales up, the size of the state space grows exponentially, presenting a severe challenge for standard uninformed algorithms. This project analyzes the theoretical bounds of this complexity and demonstrates how informed heuristic search ($A^*$) mitigates exponential explosion.

Q1: Formal Problem Formulation

To mathematically define the multi-agent convergence search, we construct the formal AI search model:

State Space ($S$)

A state $s \in S$ represents the exact position of all $n$ Pac-Men. It is a tuple of coordinates: $$s = (p_1, p_2, \dots, p_n)$$ where each $p_i = (x_i, y_i)$ is a coordinate on the grid representing the cell of Pac-Man $i$.

Initial State ($s_0$)

The arbitrary starting locations of all Pac-Men: $$s_0 = (p_{1,0}, p_{2,0}, \dots, p_{n,0})$$

Action Space ($A(s)$)

An action represents simultaneous movements for all $n$ agents. It is a joint action tuple: $$a = (a_1, a_2, \dots, a_n)$$ where $a_i \in \{\text{Up, Down, Left, Right, Stay}\}$. An action is legal iff no agent moves out of grid bounds or into a wall ($1$).

Transition Model ($T(s, a)$)

A deterministic transition function mapping current state and joint actions to the successor state: $$T(s, a) = s'$$ where the $i$-th agent's position updates to $p_i' = p_i + a_i$.

Goal Test ($Goal(s)$)

The target condition. A state is a goal state if and only if **all Pac-Men share the identical grid cell**: $$p_1 = p_2 = \dots = p_n$$ For a maze containing $M$ non-wall cells, there are exactly $M$ distinct possible goal states.

Path Cost ($C$)

Each step represents one simultaneous tick of time. Thus, the transition cost is uniform: $$c(s, a, s') = 1$$ The cumulative path cost is simply the total number of time steps required for convergence.

Q2 - Q4: Complexity and Scaling Limits

Q2: Exact Size of the State Space

Since each of the $n$ Pac-Men can be positioned independently on any of the $M$ valid non-wall cells of the maze, the total size of the state space grows exponentially as: $$\text{State Space Size} = M^n$$

Academic Example (from project PDF):
For a maze containing $M = 100$ free cells and $n = 5$ Pac-Men, the total state space size is: $$100^5 = 10,000,000,000 \quad (10 \text{ billion states!})$$

Q3: Branching Factor Upper Bound

At each step, a single Pac-Man has at most 5 choices (Up, Down, Left, Right, or Stay). Since all $n$ agents make choices simultaneously, the maximum branch combinations from any state is: $$\text{Branching Factor } B \le 5^n$$

Academic Example:
For $n = 5$ Pac-Men, the maximum branching factor is: $$5^5 = 3,125 \text{ successor states per step!}$$

Q4: Uniform Cost Search (UCS) Tree Node Expansion Limit

Since transition costs are uniform ($c=1$), UCS behaves identically to **Breadth-First Search (BFS)**. The absolute theoretical maximum number of expanded nodes is bounded by the branching factor $B$ and the maximum height of the optimal solution path $h$: $$\text{Nodes Expanded} \le \sum_{i=0}^{h-1} B^i$$

Determining maximum height ($h$):
The worst-case convergence depth happens when the agents must cover the maximum possible distance. The optimal meeting cell will minimize the distance to the farthest agent. The cell that minimizes the maximum distance to all other cells is the **radius** of the maze graph. For a connected graph of $M$ cells, the radius is bounded by: $$h \le \lfloor \text{Diameter} / 2 \rfloor \le M/2$$ Substituting $B = 5^n$ and $h \le M/2$, the theoretical node budget upper bound is: $$\text{Node Limit} = \sum_{i=0}^{M/2 - 1} (5^n)^i$$

Q5: Heuristic Admissibility & Pruning

A heuristic function $h(s)$ is **admissible** if it never overestimates the actual cost to reach a goal state (i.e. it is always optimistic, $h(s) \le h^*(s)$).

Heuristic A: Number of coordinate pairs on different cells

$$h_A(s) = |\{(i, j) : i < j \text{ and } p_i \neq p_j\}|$$ Verdict: NOT Admissible

Counterexample Proof:
Consider a flat $5 \times 5$ maze with no walls, and $n=5$ pacmen located in a cluster where all agents are on distinct cells but only 1 step away from a central target cell.
  • Since all 5 pacmen are on different cells, the number of distinct pairs is: $$\binom{5}{2} = 10 \text{ pairs} \Rightarrow h_A(s) = 10$$
  • However, in a single simultaneous step, all 5 agents can move into the central cell, gathering everyone. The actual step cost is: $$h^*(s) = 1$$
  • Since $10 > 1$, $h_A(s) > h^*(s)$, proving that this heuristic overestimates the cost, rendering it **inadmissible**.
Heuristic B: Max Coordinate Spread Divided by 2

$$h_B(s) = \frac{1}{2} \max \left( \max_{i, j} |x_i - x_j|, \max_{i, j} |y_i - y_j| \right)$$ Verdict: ADMISSIBLE (Informed & Optimal)

Mathematical Proof:
Consider a relaxed version of the problem where **all walls are removed**.
  1. Look at the X-axis in isolation: The two Pac-Men with the largest horizontal distance $\Delta x$ must meet. Since both can move towards each other at a maximum rate of 1 cell per step, the coordinate distance between them can shrink by at most 2 units per step. Thus, at least $\Delta x / 2$ steps are required to converge on the same x-coordinate.
  2. Look at the Y-axis in isolation: Analogously, the maximum vertical spread requires at least $\Delta y / 2$ steps to close the vertical gap.
  3. To meet on a single shared cell, both gaps must be closed. Therefore, the minimum steps required is bounded by the larger of the two: $$\text{Steps} \ge \max(\Delta x / 2, \Delta y / 2)$$
Adding walls back into the grid can only block straight-line paths, which **never decreases** the real travel distance. Therefore, the optimal cost in the real maze $h^*(s)$ will always be $\ge$ the relaxed straight-line cost $h_B(s)$. Hence: $$h_B(s) \le h^*(s) \quad \forall s \in S$$ This mathematically guarantees that $h_B(s)$ is **admissible**.

Q6: Search Algorithm Architectures

We implement two distinct search strategies in python to solve this multi-agent search problem:

1. Recursive Depth-First Search (DFS)

DFS explores paths depth-first, using a visited set to avoid cycles. Since there are no heuristic directives, and the branching factor is extremely high ($5^n$), pure DFS can loop indefinitely.

DFS Protections:
To prevent out-of-memory or endless runtimes, the implementation incorporates:
  • Depth Limit: Max recursion depth set to $40$ steps.
  • Node Expansion Cap: Hard stop at $400,000$ visited nodes (throwing an unwinding exception).

Note: DFS does not guarantee optimal path length and frequently returns highly redundant paths.

2. A* Search with Priority Queue

A* uses our admissible coordinate-spread heuristic $h_B(s)$ alongside actual step-cost $g(s)$ to prioritize state expansion.

A* Mechanics:
  • Min-Heap Priority Queue: Always pops the state with the lowest $f(s) = g(s) + h_B(s)$.
  • Closed Set: Records already finalized states to avoid redundant work.
  • Admissible Pruning: Optimally skips whole search subtrees because the lower bounds guarantee they cannot contain a shorter path than currently known.

Note: Because the heuristic is admissible, A* is mathematically guaranteed to find the absolute shortest convergence path.

Key Analysis Insights:

  1. The Power of Heuristics: In $n=5$, the state space is $10^{10}$ cells. Without a heuristic, UCS/BFS would need to expand billions of states. Our admissible coordinate-spread heuristic $h_B$ prunes the search space so aggressively that A* successfully solves $n=5$ in a practical number of node expansions (roughly $10^5$ to $10^6$ nodes), representing a $10,000\times$ improvement in efficiency!
  2. Uninformed Blindness of DFS: DFS is fast per node, but completely blind. By $n=3$, DFS hits the 400,000 node expansion cap in 66% of cases, returning "Did Not Finish" (DNF). The DFS execution times for $n \ge 3$ of ~0.09 seconds just indicate the time taken to burn the entire budget of 400,000 nodes and give up.
  3. Solution Suboptimality: Even at $n=2$ where DFS finishes, the path lengths are highly sub-optimal (e.g. 19-20 steps compared to A*'s optimal 6-8 steps).
